## 后端

### 新增 API 端点

在 `backend/app/api/v1/reports.py` 中新增：

| 方法 | 路径 | 功能 |
|------|------|------|
| GET | `/reports/test-plans/{plan_id}/summary` | 测试计划报告统计数据 |
| GET | `/reports/test-plans/{plan_id}/export-pdf` | 导出计划报告为 PDF |

**`/summary` 响应结构：**

```json
{
  "plan": {
    "id": 1, "name": "Sprint 8.2 测试",
    "status": "active",
    "start_date": "2026-03-01", "end_date": "2026-03-15"
  },
  "overview": {
    "total": 30, "executed": 25, "passed": 20,
    "failed": 3, "blocked": 2, "skipped": 0, "pending": 5,
    "pass_rate": 80.0, "execute_rate": 83.3
  },
  "type_distribution": {
    "api": 12, "functional": 18
  },
  "items": [
    {
      "case_type": "api", "case_id": 1,
      "case_name": "登录接口测试",
      "priority": "P0", "status": "passed",
      "comment": "", "executed_at": "2026-03-05T10:00:00"
    },
    ...
  ]
}
```

**PDF 导出：**

```bash
pip install weasyprint
# 或（更轻量）
pip install reportlab
```

推荐使用 `weasyprint`：将报告 HTML 模板渲染为 PDF，样式更灵活。

```python
# backend/app/services/report_pdf_service.py
from weasyprint import HTML

def generate_plan_report_pdf(plan_id, db):
    data = get_plan_summary(plan_id, db)
    html_content = render_template("plan_report.html", data=data)
    pdf_bytes = HTML(string=html_content).write_pdf()
    return pdf_bytes
```

HTML 模板放置于：`backend/app/templates/plan_report.html`

### PDF 导出按钮

```tsx
const handleExportPDF = async () => {
  const response = await api.get(
    `/reports/test-plans/${planId}/export-pdf`,
    { responseType: 'blob' }
  )
  const url = URL.createObjectURL(response.data)
  const a = document.createElement('a')
  a.href = url
  a.download = `测试报告-${planName}.pdf`
  a.click()
}
```
